Evidence vocabulary

SOURCE_AUDITED means inspected, not tested. IMPLEMENTED means code exists, not that it passed. TEST_VERIFIED must be tied to exact commit, command, environment and results. INDEPENDENTLY_VERIFIED requires independent evidence. ACCEPTED requires owner approval.
